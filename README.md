# Feelnet

**Global Network Intelligence for the Feelcoin blockchain.**

🌍 https://net.feelcoin.org

Feelnet is an interactive network intelligence dashboard
for the Feelcoin (FEEL) blockchain.

## Features

- Interactive global network atlas
- Zoom, pan and mobile touch navigation
- Official Feelcoin node visualization
- Observed P2P connection visualization
- Geographic distribution of observed network peers
- Network statistics and historical activity
- Responsive design with Feelcoin branding

## Network data

Feelnet visualizes network observations gathered from
official Feelcoin nodes.

Geographic coordinates represent approximate country
locations, not individual peer positions.

The public dashboard does not disclose peer IP addresses.

Connections between third-party peers cannot be inferred
from the official nodes' observations.
